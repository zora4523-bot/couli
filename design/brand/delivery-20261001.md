## 验证结果

- 14 个 SVG 均可解析；Logo 与 App 图标使用矢量路径，没有 `<text>`、脚本、外链位图或 `foreignObject`。中文字标已转曲。概览的说明文字保留可编辑文本。
- 7 个 Logo PNG 全部宽 2048 px、保留透明背景。横版、竖版、单色与反白均有源稿和导出稿。
- 4 个 App 图标 PNG 全部为 1024×1024。默认图标与背景为 RGB、不含透明通道；前景与单色层为 RGBA，透明与不透明像素均存在。没有预裁圆角。
- 前景可见像素距画布中心最大约 290.7 px，处于团队选用的直径 66% 圆形范围内；该范围为跨平台构图留白约定，不宣称是 Apple 的固定比例。最终系统遮罩仍须实测。
- JSON 可解析，78 项令牌均有 CSS 对应。颜色、尺寸与字体数值核对一致；对比度按 sRGB 公式计算。白字 / 主橙为 4.89:1，米白上的品牌小字改用深橙，避免主橙 4.41:1 的组合。
- Playwright 在 1440×1000 桌面与 390×844 手机视口检查，均无页面横向溢出；全部本地图片加载成功，控制台 0 error / 0 warning。已目视检查桌面首屏、交互区、手机全页与手机商品卡。
- 操作验证通过：默认/深色/单色控件可选择、深色资源正确切换；复制狸橙后提示「已复制 #C44820」；进入 AI 后示例问题出卡；查看商品可打开弹窗，Escape 可关闭；查返利进度可切到订单；首页与我的导航正常。示例金额已按项目格式去尾零。
- 展示页本地资源与文档相对链接检查、`git diff --check` 通过。检查过程截图与浏览器日志只作本地 QA 临时材料，不纳入品牌源文件提交。
- 本仓库没有应用工程或构建、lint、单元测试入口；本次验证针对素材、配置、文档与展示页，不报告应用测试通过。
