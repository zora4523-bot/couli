- 背景：2026-10-05 取回的 MobPush 官方文档显示有原生鸿蒙 SDK（公开下载页 V2.3.7、集成指南要求 API 12+，鸿蒙离线消息经华为 Push Kit 通道下发）。来源：私有库 `rebate-private/docs-mirror/mobpush/DEV-NOTES.md`、`pages/harmony-integration.md`、`pages/harmony-channel-setup.md`，官方页 https://www.mob.com/wiki/detailed?id=136&wiki=697 、https://www.mob.com/wiki/detailed?id=136&wiki=781 。文档已确认，未实测。

## 1. 决定内容

1. 三端推送都经 **MobPush SDK**：iOS 经 MobPush 走 APNs，Android 经 MobPush 走华为、荣耀、小米、OPPO、vivo 厂商通道，鸿蒙经 MobPush 鸿蒙 SDK，底层仍是华为 Push Kit 通道。
2. 后端推送 Adapter **只接 MobPush 一家**，不再单独接 Push Kit 服务端接口（05 B1-12）。Adapter 接口不变（02 §1 第 4 条「外部依赖一律过治理层」）。
3. 鸿蒙端仍需在华为 AGC 的凑狸项目里**开通推送服务（Push Kit）**，按 MobPush 鸿蒙集成文档：在 App 模块的 `module.json5` 配置华为 client_id；在华为侧创建服务账号密钥，把下载的凭据文件上传到 MobPush 后台的鸿蒙通道配置（以 MobPush 鸿蒙配置文档为准，接入时按当期文档核对）。
4. 服务端凭据：我方服务端只持 MobPush 的服务端 AppSecret（KMS）；华为 Push Kit 的服务账号凭据配置在 MobPush 控制台，不进我方服务端（02 §12.6）。凭据交给 MobPush 托管是否需要在隐私政策或供应商登记里说明，接入时按 MobPush 隐私政策核对（待核实）。
5. 鸿蒙 App 的第三方 SDK 清单加 MobPush：同意隐私政策后才初始化，并按 MobPush 鸿蒙隐私合规文档在用户同意后回传隐私授权结果（用户不同意时不能调用、不能无条件传同意）；按其鸿蒙可选采集接口关掉与推送无关的采集（03 §3.5）。
