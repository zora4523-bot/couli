# 凑狸品牌色 · 第二版提案

版本：2026-10-01 / revised proposal v0.2.0。根据本轮品牌设计与独立评审修订授权配色，供设计与开发评审使用；尚不代表最终品牌验收。MVP 只做浅色 UI，深色主题留到 P1（规划/03 §10.1）。App 图标的深色外观素材独立于 App 内的主题支持。

方向：**狸橙 + 松叶绿 + 暖米白**。狸橙表达亲近、行动与发现优惠；松叶绿用于可信的完成反馈；米白与深色文字降低商品信息流的视觉噪声。主色集中用于主要行动、选中图形与品牌标记，不把整页价格和信息都染成橙色。

## 1. 语义配色

## 2. 主按钮与状态

| 状态 | 背景 | 文字 | 交互说明 |
| --- | --- | --- | --- |
| 正常 | `#C44820` | `#FFFFFF` | 每个主要任务区域保持一个清晰主行动 |
| 按下 | `#A83B1F` | `#FFFFFF` | 即时反馈；不通过改变布局尺寸造成跳动 |
| 禁用 | `#E9E2D9` | `#655E57` | 同步禁用语义；必要时给出原因 |
| 键盘聚焦 | 当前状态 + `#26735B` 焦点环 | 当前状态 | 2 单位实线，距控件 2 单位；周围留白保证可见 |

链接与选中项必须同时有下划线、形状、文字或图标等线索。金额保持墨棕或中性文字，使用字号 / 字重表达层级；状态单独承载含义。预估返利与等待结算使用中性浅底、钟表图形和明确状态词；已结算使用绿色浅底、完成对勾和明确状态词。即使去掉颜色，两者也能区分。状态文案与金额口径仍以 BR-TEXT-01、BR-TEXT-04 和 BR-FUND-04 为准，本表不重新定义业务状态。焦点环通过控件外轮廓与状态徽标区分，规则适用于键盘 / 辅助输入，不以常驻描边替代系统原生焦点行为。

## 3. 对比度实测

计算日期：2026-10-01。按 sRGB 相对亮度计算，以下为不透明实色组合，保留两位小数。普通文本采用至少 4.5:1；必要控件边界与焦点线采用至少 3:1 的设计验收目标。实际页面叠加透明度、图片、渐变后需重新验证。

| 前景 / 背景 | 比值 | 结论 |
| --- | ---: | --- |
| 白字 `#FFFFFF` / 主色 `#C44820` | 4.89:1 | 普通按钮文本通过 |
| 白字 `#FFFFFF` / 按下态 `#A83B1F` | 6.34:1 | 普通按钮文本通过 |
| 主文字 `#28251F` / 暖米白 `#F6F3ED` | 13.79:1 | 通过 |
| 主文字 `#28251F` / 白色 `#FFFFFF` | 15.28:1 | 通过 |
| 次文字 `#655E57` / 暖米白 `#F6F3ED` | 5.76:1 | 通过 |
| 次文字 `#655E57` / 白色 `#FFFFFF` | 6.38:1 | 通过 |
| 强调文字 `#A83B1F` / 白色 `#FFFFFF` | 6.34:1 | 通过 |
| 强调文字 `#A83B1F` / 暖米白 `#F6F3ED` | 5.73:1 | 通过 |
| 强调文字 `#A83B1F` / 品牌浅底 `#FBEFE8` | 5.62:1 | 通过 |
| 价格 `#28251F` / 白色 `#FFFFFF` | 15.28:1 | 通过，靠字号与字重突出 |
| 待定 `#655E57` / 待定浅底 `#EFEAE2` | 5.33:1 | 通过 |
| 成功 `#26735B` / 成功浅底 `#EAF4EE` | 5.07:1 | 通过 |
| 警告 `#846020` / 警告浅底 `#FBF2DC` | 5.13:1 | 通过 |
| 错误 `#B42345` / 错误浅底 `#FDECF0` | 5.64:1 | 通过 |
| 禁用文字 `#655E57` / 禁用底 `#E9E2D9` | 4.97:1 | 仍保留可读性 |
| 焦点环 `#26735B` / 白色、暖米白 | 5.70:1 / 5.14:1 | 必要图形通过 |
| 控件边界 `#8A8177` / 白色、暖米白 | 3.83:1 / 3.46:1 | 必要图形通过 |
| 主色 `#C44820` / 暖米白 `#F6F3ED` | **4.41:1** | **不可用作普通小字；改用强调文字令牌** |

公式：先将 RGB 的 0–255 通道除以 255 得到 `c`，若 `c ≤ 0.04045` 则线性通道为 `c / 12.92`，否则为 `((c + 0.055) / 1.055)^2.4`。相对亮度 `L = 0.2126 R + 0.7152 G + 0.0722 B`；对比度为 `(较亮 L + 0.05) / (较暗 L + 0.05)`。

## 4. Apple 指南的落实

采用语义颜色、保留足够对比、避免仅靠颜色传达状态，并将品牌色用于聚焦主要行动，依据 [Apple HIG · Color](https://developer.apple.com/design/human-interface-guidelines/color) 与 [Apple HIG · Accessibility](https://developer.apple.com/design/human-interface-guidelines/accessibility)（核对日期：2026-10-01）。

团队采用至少 44 × 44 的逻辑触控命中区，iOS 按 44 × 44 pt，Android / 鸿蒙在本方案采用 48 × 48 dp / vp；这是团队选用的推荐尺寸策略，不是声称 Apple 对所有平台都规定统一的 44 pt 硬性下限。字体使用系统字体并响应系统字号，颜色验收不能代替 Dynamic Type、VoiceOver、焦点顺序与真实设备检查。H5 基础控件提供 `forced-colors` 系统颜色回退；这不等于已经通过 Windows 高对比或 iOS 增强对比验证。实现必须分别检查系统强制配色、增强对比、200% 文字放大、灰度及色觉障碍下的状态辨识，确认字号和布局不会遮挡标签或操作。

机器可读值见 [design-tokens.json](../tokens/design-tokens.json)，H5 变量与用法见 [tokens/README.md](../tokens/README.md)。
