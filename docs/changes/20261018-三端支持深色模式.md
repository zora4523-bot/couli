## 1. 负责人决定

2026-10-18：**三端开发时一起支持深色模式**。编排落实口径（代理按 00 §9 自定实现方案，可由后续评审修订）：

1. **组件库两态**：05 DS-02 组件库交付浅 / 深两套令牌映射与全部组件的深色态，组件目录页带浅 / 深切换；页面经令牌自动跟随系统深色设置，业务代码不感知主题。
2. **关键页深色稿**：关键页定稿时附深色稿——登录 4 张先出；首页、详情、订单、钱包、我的在各自定稿批次加深色版；其余页面由实现按令牌推导，Codex 评审时抽查深色截图。
3. **快照基准**：三端快照 / 截图基准各加一套深色（与 iOS 26 基准同级），数量翻倍可接受。
4. **H5 与后台**：H5 与管理后台同样按令牌支持深色，后台优先级最低、排在三端与 H5 之后。
5. **华为预审**：仍可做，用于核对深色实现是否满足华为口径，但不再是鸿蒙首次提审的前提（06 Q-G21）。

代理补全的默认（可由 Jev 判断或负责人推翻）：App 内不单做主题开关、只随系统；深色取值由 DS-02 补进 `design/tokens/design-tokens.json` 这一个唯一源（语义令牌名只有一套，按主题映射到不同数值）；AC-S1-185 为条件项、随 DS-02 与各页定稿后验收、不计入 S1 出门；后台深色在 M-公开后做。
