## 1. 内容

1. **同一骨架**：淘宝、京东、拼多多的详情页模块顺序与位置一样——主图（通栏、多图带页码，顶部只留浮在图上的返回键）→ 价格大字 → 券标签 → 平台文字标签 + 标题（拼多多加销量）→ 店铺块 → 价格走势 → 反馈入口 → 底栏。平台差异只有「字段有就显示、没有整块不显示」与口径词（拼多多「拼单」）。逐模块的显示条件见 `design/specs/app-product-detail.md` 与设计稿说明的字段显隐表（01 F-PROD-05）。
2. **价格区**：大字只放主价；不再显示「券前 ¥x · 券 ¥y」副行、「有券」标签、「无券」与「以结算为准」；有券时主价下方显示券标签「¥y 券 · {失效时刻} 前有效」（BR-PRICE-04 细则「商品详情的券标签」）。只改商品详情，列表卡、AI 卡、分享页照旧，列表卡改版时按组件规范统一。
3. **返利只在主按钮**：价格区不放返利；底栏主按钮一行「购买预估返 ¥x」，有券无券同一句（拍板第二批 TRADE-21 的按钮文案由负责人改定）；负责人原话的「返现」是 BR-TEXT-13 资金类禁用词，金额前也须带「预估」（BR-PRICE-05），按他 r12 自己写的「购买预估返 ¥2.34」落实；拿不到金额「购买可返利」，需登录看返利「登录查看返利」。列表卡、AI 卡的购买按钮同句式（同一组件）。新键 `btn.buy.rebate`、`btn.buy.rebate_unknown`；`btn.buy.rebate_suffix`、`btn.buy.coupon` 保留不用，`btn.buy` 改为「购买」（BR-TEXT-12 细则「购买按钮」、BR-TEXT-14 表 C）。
4. **组合胶囊**：规划里已有的公开版【分享赚】补到底栏，与主按钮拼成组合胶囊（左段【分享赚】、右段主按钮压上去，纯色）；内测期按 TRADE-21 不出左段（03 §10.2 `BuyBar`，01 F-PROD-05、F-SHARE-10）。
5. **平台文字标签**：标题前改为实底文字标签（淘宝 / 天猫按 `shop_type` / 京东 / 拼多多），与标题同一段文字、折行顶格；首页、搜索、收藏、热销榜、AI 卡、订单卡同样改（r8：负责人说这类改动「不需要我定」，按规划好的组件为标准）（03 §10.2 `PlatformBadge` 标题标签形态，BR-TEXT-14 表 C `platform.tag.*`）。画板取的颜色：淘宝 `#D53D00`、天猫 `#EA0031`、京东 `#E02018`、拼多多 `#EB0007`（取各平台标识主色、加深到白字对比度 ≥ 4.6:1，深浅色同色），待登记 `design/tokens`（§7）。
6. **店铺块与进店**：「头像（店铺 logo → 平台徽标 → 通用店铺图标）+ 店名 + 接口真给的评分 + 右侧【进店】」；评分只放拼多多描述 / 服务 / 物流三项与京东店铺等级（满分刻度核实前原样数字），淘宝不放；【进店】点击时经服务端转链跳平台店铺页，淘宝先用大淘客店铺转链、后台可切换来源，不加进店前提示，拿不到带用户归因的店铺链接就不显示（BR-PRICE-21 细则「进店」，取代 2026-10-03「P1 候选」；开关 `shop.entry.enabled.<platform>` 默认关）。
7. **销量与店铺评分**：先只上拼多多，按平台开关（`detail.sales.enabled.<platform>`、`detail.shop_scores.enabled.<platform>`，默认关），09 实测登记字段格式后打开；只原样显示接口值，不自算、不估（BR-TEXT-13 细则「虚拟数据」）。
8. **价格走势**：展开区加「当前」「近 30 天最常见价」两个数据块与一句统计口径；中性统计，不写比较词、不进摘要模板句（01 F-PROD-14 ⑧，BR-TEXT-13 细则「降价表述」）；拼多多用「拼单券后价 / 拼单价」写法（⑨）。
9. **商品反馈**：价格走势下方一行「价格或返利不对？反馈给我们」，半屏四个原因必选一个、补充说明选填，内测期上（01 F-PROD-15，接口待契约）。
10. **不展示的内容**：预估返后价（商品详情、列表卡、AI 卡都不展示，`est_net_price_fen` 照常下发、客户端不读，BR-PRICE-09）；正常态的「取价 HH:mm」（报价降级提示保留，BR-PRICE-11）；口径小字三句（price_basis / price_basis.general、rebate_estimate、入账说明「确认收货后随联盟月度结算入账」）——放进帮助中心文章「价格与返利说明」，入账说明在 PAID 订单页照旧（BR-PRICE-03、BR-PRICE-17、BR-TEXT-04）。
11. **无返利商品不出现在 App**：搜索、首页物料流、AI 检索本来就按 BR-PRICE-08 过滤；粘贴链接或口令、收藏夹、深链与链接直达详情等入口取到 no_rebate 时只提示「这件商品暂无返利」（`no_rebate.notice`），不出商品卡、详情与购买按钮（BR-PRICE-08，三态里的「无返利」只作推导与统计，BR-PRICE-21）。不受影响：amount_unknown「购买可返利」、login_required、点击时才变成无返利的卡（返利归零、券失效且返利归零、拼多多比价预判「这次没有返利」）、50303 与授权失败时的【仍去购买（无返利）】。

**列表页口径说明（代理判断，未改）**：负责人 r13 只说了详情页。搜索列表、首页物料流、热销榜、Agent 卡片流的「每屏底部一次全文 + 单卡 i 图标」本次不动，理由：① 原话指的是详情页那块常驻小字，「这里」不包括列表；② 列表的写法是另一种呈现（每屏一行加卡上的图标），不是同一块组件外观，r8 的「组件一致」管的是同一个组件；③ 列表页没有详情页那样的反馈入口，口径句是用户看到价格差异时唯一的说明。是否一起去掉列入 §7 待跟进。分享海报、分享中间页、分享文案的口径句不动。
