## 1. 决定内容

1. iOS、Android 的推送聚合服务定为 **Mob 推送（MobTech MobPush）**：iOS 经 MobPush SDK 走 APNs，Android 经 MobPush SDK 接华为、荣耀、小米、OPPO、vivo 厂商通道。
2. 取代拍板第二批 TECH-14 的前半句「按有无鸿蒙 SDK 在极光、个推中选一家（W1 定）」。05 §5「W1 人工清单」第 10 项与 §1 W1 周计划里的推送选型随之关闭。

## 4. 受影响的页面与接口

- 页面：无（推送开关、消息中心、提醒设置页不变）。隐私政策与「第三方 SDK 清单」页面内容要把推送 SDK 写成 MobPush（法务重写时按 03 §3.5）。
- 接口与契约：无。设备推送令牌上报接口（`push_tokens`）存的是 MobPush 的设备标识（registrationId）或鸿蒙 Push Kit 的 token，字段形状不变；如 MobPush 的设备标识长度、字符集与现有字段约束不符，由契约任务按 04 形状调整。
- 代码仓库：notification 模块尚未开工（B1-12 只做了迁移 B1-12a），无需改代码。
