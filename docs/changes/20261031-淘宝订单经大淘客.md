# 2026-10-31 淘宝订单数据改经第三方订单源大淘客

- 决定人：负责人（2026-10-31 01:25 在编排会话里要求把大淘客开发文档整理进项目、「确保完成你所需要的信息」；同日 13:5x 确认「淘宝已改用第三方订单源大淘客」）。
- 类别：00 §8 第 ② 类（新增第三方供应商；订单数据来源变化）。

## 1. 内容

1. 淘宝推广订单、维权订单、违规（处罚）订单不再等联盟官方「推广订单及数据查询」权限，改经大淘客开放平台取数：订单 `get-order-details`、全量维权 `get-order-refund`、违规订单 `get-foul-order-list`（接口事实见私有库 `rebate-private/docs-mirror/dataoke/DEV-NOTES.md`）。
2. 官方订单接口邀请制：联盟客服 2026-10-31 答复门槛为违规 < 18 分、近 30 天日均访客 ≥5 万、日均成交 ≥10 万；凑狸应用上授权版（sc）订单接口没有申请入口（规划/09 §2.10）。
3. 字段口径不变：大淘客订单返回与官方 `publisher_order_dto` 同名同义，系统内部仍按官方字段映射（规划/09 CAP-TB-07、08 BR-FUND-01 / 02 不改）。大淘客自算的 `income`、`price_by_one` 等字段不使用。
4. （2026-10-31 晚：淘宝搜索与转链部分已由 `docs/changes/20261031-淘宝搜索与转链经大淘客.md` 取代）只用订单类接口，不接大淘客选品库（规划/07 第三方选品库一行「不做」不变）；淘口令、商品详情、短链仍走凑狸应用的官方接口。

## 2. 受影响的规划与代码

- 规划/09 §2.10、CAP-TB-07：订单数据源登记为大淘客；官方订单接口仍为未开通。
- 代码仓库 union 模块：淘宝适配器的 `listOrders` 与维权 / 违规查询经大淘客实现（联盟线入账），凭据只从环境变量与文件读取（同拼多多做法：staging 文件、prod 只认 KMS、local / test 不加载真实凭据）。
- 08 无变更。

## 3. 风险与约束（负责人已知悉，2026-10-31 调研报告 `couli-runs/research/taobao-order-providers-20261031.md`）

- 订单经大淘客服务器中转，大淘客的「订单统计」模块会读取授权账号的订单，数据保留期未查到。
- 联盟规定服务商不得把原始订单明细给第三方；联盟每年考核服务商，未达标会收回权限——大淘客失去资格时订单同步会中断，需监控订单同步水位告警（规划/02 §13 已有「同步水位延迟 > 30 分钟」）。
- 授权 90 天要负责人本人续一次，过期即停。
- 所用联盟账号（真捣蛋哈）凑狸与优券汇共用，大淘客能看到两边全部订单；同步时按凑狸的推广位过滤，不入库别家订单。
- 隐私政策须写明订单数据经第三方服务商处理（法务文本，规划/06 F 节）。

## 4. 验收与恢复

- 验收：编排用凑狸授权账号做只读实测（≤20 次，字段只记形状），订单、维权、违规三类各有记录；代码仓库订单同步在 staging 拉到淘宝订单并按推广位归属。
- 恢复：联盟官方订单权限批下后，淘宝适配器改回官方接口（字段同名，映射不变），关掉大淘客数据源开关即可。
