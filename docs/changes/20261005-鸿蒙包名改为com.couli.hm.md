# 变更记录：鸿蒙包名改为 com.couli.hm

- 日期：2026-10-05
- 类型：00 §8 第 ② 类。改变已确认的决定（拍板第二批 TECH-08 之后、负责人 2026-10-02 确认的「三端包名统一为 `com.couli.app`」）。负责人 2026-10-05 在 Codex 桌面版会话里决定，按仓库约定直接写回并注明日期。
- 状态：已决定，规划已写回（§3）。华为 AppGallery Connect 已按此创建凑狸鸿蒙应用。
- 原话（两次选择）：先选「鸿蒙使用 com.couli.harmony」；华为校验以 `harmony` 为保留字符拒绝后，选「使用 com.couli.hm」。
- 涉及 BR：无。08 没有包名取值，不改。

## 1. 决定内容

1. 鸿蒙 Bundle Name 定为 **`com.couli.hm`**。
2. iOS Bundle ID 与 Android 包名不变，仍为 **`com.couli.app`**（含华为渠道 Android 包）。
3. 原因：华为 AGC 创建 HarmonyOS 应用时，创建页写明包名必须唯一，鸿蒙应用包名也不能与 Android 应用包名相同；凑狸的 Android 包名已是 `com.couli.app`，所以鸿蒙必须另取。`com.couli.harmony` 因含保留字符被平台拒绝。
4. 现状：凑狸鸿蒙应用已在 AGC 新项目「凑狸」下创建（APP ID 已生成，数值不进公开仓库）；未生成发布证书与 Profile，未申请 Push Kit 等可选能力，未上架。来源：私有库 `rebate-private/docs-mirror/huawei/CONSOLE-AUDIT-2026-10-05.md`、`couli-runs/codex-docs-report-2.md`。

## 4. 受影响的页面、接口与按包名配置的地方

页面与后端接口：无。下面是按包名或应用标识配置、接入时要用对值的地方：

| 地方 | 用哪个值 | 说明 |
| --- | --- | --- |
| iOS Universal Links（`apple-app-site-association`） | `<Team ID>.com.couli.app` | 不变 |
| Android App Links（`assetlinks.json`） | 包名 `com.couli.app` + 发布签名 SHA256 | 不变 |
| 鸿蒙 App Linking（`applinking.json`） | `appIdentifier` 填鸿蒙应用的 **APP ID**，不是包名 | 华为文档按 APP ID 关联域名；现在要用新建的凑狸鸿蒙应用的 APP ID（只在私有运维记录与生成物里出现）；核对前鸿蒙不声明 https 链接的规则不变（03 §4.5、09 CAP-X-03 步骤 6） |
| `contracts/apps.json` 与三端生成物 | 鸿蒙端的自身 bundleName 用 `com.couli.hm` | 入站回调、查询声明由生成器按端取值；外跳目标（淘宝、京东等）的包名不受影响 |
| 微信开放平台移动应用 | iOS Bundle ID、Android 包名 `com.couli.app`；鸿蒙 Bundle ID `com.couli.hm` 与 identifier | 06 Q-C12、05 §5 第 14 项 |
| 百川（淘宝）鸿蒙版 | 鸿蒙 Bundle Name `com.couli.hm`，另走加白 | 已建的 iOS、Android 百川应用包名只读，不能复用（09 5_X §5.5） |
| MobPush 应用 | 三端分别登记；鸿蒙填 `com.couli.hm` | 见 `docs/changes/20261005-鸿蒙推送改走Mob.md` |
| 华为账号登录、推送的 client_id | 属于新建的凑狸鸿蒙应用 | 华为渠道 Android 包另属 AGC 里的 Android 应用 |
| 鸿蒙发布证书、Profile、签名指纹 | 按 `com.couli.hm` 生成 | 06 Q-C3 冻结指纹时登记；App 备案按各端实际包名填 |
| H5 | 无 | H5 不按包名判断来源 |
