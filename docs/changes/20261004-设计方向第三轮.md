## 4. 界面布局决定（只登记，不改业务规则）

**内容**（负责人 2026-10-04 确认方向，各设计组按出稿规范落到稿面）：

1. **列表商品卡**（搜索、AI 卡、收藏夹、热销榜共用）：左图右文；平台来源标签放标题最前；优惠标签一行（没有就不出）；价格行为口径词 + 主价 + 返利标签；卡片底行左侧放口径说明、右侧放主按钮（取代 2026-10-04 审查闭环决定 §2 的「按钮在价格行右侧」）。返利为单一金额时按钮写「领券购买 · 预估返 ¥x」/「去购买 · 预估返 ¥x」，动词仍是 08 已有的 `cta.text_key`（BR-TEXT-12 细则 TRADE-21）；区间只写动词，不写「起」或上下限；无返利仍是「去购买（无返利）」；放不下时按钮整块换行，不缩字号、不截断金额。首页网格卡、横滑卡、详情页、分享页、链接落地页不是这种卡，只换用色。

3. **「我的」页**：身份卡 + 可提现余额卡 + 分组宫格（订单与钱包；推广与邀请；更多服务），钱包只从宫格进入。

**涉及 BR**：BR-TEXT-14 表 C 新增 `btn.buy.rebate_suffix`（「· 预估返 {amount}」）——只登记键与「何时拼」：单一金额（rebate_min_fen = rebate_max_fen > 0）、rebate_basis 不是 no_rebate / amount_unknown / login_required、金额未隐藏（BR-TEXT-10 细则「金额隐藏」）、所在页面显示返利金额（`LinkLanding`、分享中间页、海报不拼）；金额与同卡返利标签用同一格式化结果（BR-TEXT-10）。BR-TEXT-12 细则「资金术语键」单列的键补这一个（带金额变量，按 ③④ 归入）。键名与条件是代理补全的默认，待负责人确认（06 第 8 项）。其余各项不涉及规则取值：钱包字段口径 BR-FUND-18，订单金额与状态词 BR-TEXT-01、02、04，收益看板 BR-FUND-25 均不变。

**A. 热销榜的名次与销量**（§5 第 1 项的排序口径、名次来源、能否显示销量部分）

- 内容：名次按平台热销类物料 / 榜单接口返回的顺序；销量显示接口返回的销量字段。本系统不自己计算、重排或编造热度数字，不展示没有接口来源的数据。
- 销量写法随平台口径，只用 规划/09 已登记的字段与口径：淘宝 CAP-TB-03 登记 `volume` 为 30 天销量（模糊值，原样显示），稿面写「近 30 天销量 …」；京东、拼多多在 09 没有登记可作销量的字段（京东 `inOrderCount30Days` 是 30 天引单量，属联盟推广口径，不当销量显示），稿面写「销量（以平台返回为准）…」中性标签，实测登记后再按 09 改。列表顶部说明「名次与销量来自平台，按平台返回的顺序排列」。用户侧仍不出现「高佣」「收益榜」「飙升」和「近 2 小时推广 N 件」一类联盟推广口径。
- 仍未定（保留在 规划/06「设计方向第三轮待确认」第 1 项，P1 立项前补）：各平台用哪个接口 / 频道（依赖 CAP-TB-10、CAP-JD-10、CAP-PDD-10 记下排序依据与是否含佣金权重，进 `specs/material-channels.yaml` 白名单）；各平台榜单接口是否返回销量字段及口径（依赖 CAP-TB-03 / CAP-TB-10 实测 `volume`，京东、拼多多在 CAP-JD-10、CAP-PDD-10 登记销量字段）；首页入口位置。
