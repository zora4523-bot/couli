# 品牌色

填好后 Claude 据此生成 `tokens/design-tokens.json`（三端与 H5 共用，规划/03 §10.1）。只做浅色主题，深色 P1。

| 用途 | 色值 | 说明 |
| --- | --- | --- |
| 主色 | #______ | 主按钮、选中态、品牌强调 |
| 辅色 | #______ | 次要强调（可选） |
| 价格色 | #______ | 券后价、返利金额（返利类 App 常用红或橙） |
| 成功 | #______ | 已结算、提现成功 |
| 警告 | #______ | 待处理、即将过期 |
| 错误 | #______ | 失败、已失效 |

偏好说明（可选）：想要的感觉、不想要的颜色、参考的品牌等。

不确定时可以只填主色，其余由 Claude 配出 2–3 套方案供你选。
