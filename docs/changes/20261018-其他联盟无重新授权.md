# 2026-10-18 其他联盟没有「重新授权」

**来源**：负责人 2026-10-18 在对话中确认：「拼多多没有重新授权的概念，其他联盟用户都是只授权一次的。淘宝则是管理后台查看用户信息备案信息的时候可以解绑淘宝备案，不支持用户自行解绑备案。」

**起因**：后台线 F1-07c 实现拼多多的停用 / 恢复 / 重置时问「什么算重新授权」（08 BR-ID-20 原文只写淘宝）。编排同日先按 Jev 补了默认「下发过授权链接即算」（规划 #132、#133），本条按负责人决定取代。

**内容**
- 拼多多、京东等其他联盟：用户只授权（备案）一次；后台只有「停用返利 / 恢复返利」两个本平台侧开关，恢复与解封后绑定直接回到 active、立即生效，不要求重新授权。
- 「重置授权」只对淘宝：管理员在后台用户详情的备案信息里解绑淘宝备案；用户不能自行解绑（§8 ADD-01 不变）。其他平台调用重置返回 20001（`data.fields=[platform]`，代理补全的默认），界面不显示。
- 淘宝的停用 / 恢复、封禁解封后需用户重新授权，维持原规则。

**涉及**：08 BR-ID-20 正文与细则；01 F-ADM-04；04 `union.binding_reset` 行。
**受影响的实现**：后台线 F1-07c（拼多多重置不再提供、恢复即生效，去掉「下发授权链接」判定）；后台前端用户详情页的联盟授权按钮。
**验收**：拼多多绑定停用后恢复，无需用户操作即可重新获得返利归属；对拼多多调用重置返回 20001；淘宝流程不变。
**恢复方式**：回退本次 PR 即回到 #133 的口径。
