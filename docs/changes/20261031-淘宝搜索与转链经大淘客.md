# 2026-10-31 淘宝关键词搜索与转链改经大淘客

- 决定人：负责人（2026-10-31 21:2x 在编排会话里答「同意，淘宝搜索和转链先走大淘客」）。
- 类别：00 §8 第 ② 类（第三方供应商用途扩大；商品数据与推广链接来源变化）。
- 前置：`docs/changes/20261031-淘宝订单经大淘客.md`（订单、维权、违规经大淘客）。该文 §1 第 4 条「只用订单类接口，不接大淘客选品库；淘口令、商品详情、短链仍走凑狸应用的官方接口」中「不接选品库」与转链部分由本文取代，其余不变。

## 1. 内容

1. 淘宝关键词搜索（UnionAdapter `searchItems`）改经大淘客「大淘客搜索」`get-dtk-search-goods`（v2.1.2）；淘宝转链（`convert`）改经大淘客「高效转链」`get-privilege-link`（v1.3.1），`pid` 传凑狸自己的淘宝推广位（按场景取 active 推广位，BR-ATTR-08），`channelId` 传该用户的 relation_id。
2. 起因：凑狸淘宝应用没有新版权限包 27939「推广者商品物料获取」（含物料搜索升级版）与 28308「推广者万能转链」，两接口都回 code 11 `isv.permission-api-package-limit`（2026-10-31 18:12、18:24 两次实测，规划/09 §2.10）；淘宝联盟规范里链接类接口为邀请制、有流量门槛，新 App 短期拿不到。
3. 归因规则不变：转链必须带 relation_id（08 BR-ATTR-06：没有绑定返回 30101 并给授权地址，绑定失效 30102，不得不带 relation_id 转链；no_rebate 例外照旧）。用户渠道备案仍走凑狸应用已有的「私域用户管理」权限（scope 14474）。
4. 价格口径不变：08 BR-PRICE-11 的「联盟接口响应」对淘宝含经大淘客中转的响应，quoted_at 取服务端收到大淘客响应的时刻；搜索列表用大淘客返回的券后价，进入详情或打开购买前按现行规则重新取价（高效转链返回的价格与券字段），不沿用搜索列表的价。大淘客自算的预估收益字段（如 `estimateAmount`）不使用，返利仍按 08 BR-CALC 用佣金率计算。
5. 搜索结果只是大淘客自有商品库的子集，不是淘宝全量；返回的 `couponLink`、`itemLink` 不是我方推广链接，不得直接给用户，一律经第 1 条转链。
6. 并行：负责人在淘宝开放平台给凑狸应用（AppKey 尾号 9818）申请 27939、28308；批下后改为「官方优先、大淘客补充」，按端点配置切换。

## 2. 受影响的规划与代码

- 规划/07「第三方选品库（大淘客）」一行由「不做」改为本期做（只限淘宝搜索与转链）。
- 规划/09 §2.10：登记两次权限实测与大淘客搜索、高效转链实测结论（rebate-private `docs-mirror/dataoke/DEV-NOTES.md`、`docs-mirror/taobao/DEV-NOTES.md`）。
- 代码仓库 union 模块：淘宝适配器 `searchItems`、`convert` 经大淘客实现（联盟线入账），沿用大淘客请求底座（B1-04m）与凭据装配（B1-04e）；端点来源可按配置在大淘客与官方之间切换。
- 08 无变更（本文第 3、4 条是现行规则在新数据源下的适用说明，不改取值）。

## 3. 风险与约束

- 推广链接经大淘客生成：推广位与 relation_id 是否进订单，链接里看不出来，**须用一单真实测试单核对**（订单接口有 `adzone_id`、`relation_id` 字段）；测试单开始前照规划/09 README 第 5 条先取得联盟对测试单报备的书面答复（联盟账号与优券汇共用）。
- 大淘客失去服务商资格或接口变化时，搜索与转链同时中断；监控转链失败率与搜索错误率，告警后切回官方接口（若权限已批）或关闭淘宝入口开关。
- 隐私政策中「订单数据经第三方服务商处理」的表述扩到「商品与推广链接数据」（法务文本，规划/06 F 节）。

## 4. 验收与恢复

- 验收：编排只读实测已通过（大淘客搜索有权限、20 条结果均有商品 ID；高效转链用凑狸推广位转搜索结果成功，返回淘口令、短链、领券链接）；代码仓库在 staging 搜到淘宝商品、转出带我方推广位的链接；真实测试单核对推广位与 relation_id 回传。
- 恢复：淘宝应用批下 27939、28308 后，`searchItems` / `convert` 端点改回官方接口；或关闭大淘客来源开关，淘宝搜索与转链按现行规则返回不可用。
