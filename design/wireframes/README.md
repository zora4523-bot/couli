## 怎么看

- 在仓库根目录运行 `python3 -m http.server 8765 --bind 127.0.0.1 --directory design`，打开 `http://127.0.0.1:8765/wireframes/home-v20261004.html`（其余页换文件名）；也可以直接双击 HTML 文件。
- 每页并排画出该页的各个状态：左边是 375 宽的手机框，右边是编号注释。模块上的黑色编号对应右侧同号注释，注释写明功能编号（F-）、业务规则编号（BR-）、文案键与路由名。
- 黄色虚线的「待定」表示规划里还没定，线框没有替规划做决定；去哪里定写在注释和页尾的「待定项」里。
- 页尾有三块：本页覆盖的状态、待定项、请负责人确认（大白话）。
- 线框是灰阶的结构稿，不是视觉稿：品牌色只用在主按钮、强调与状态色；示例金额都是样例值。文案取 08 的现行措辞（BR-TEXT），价格与返利的展示按 BR-PRICE。
- 页面里没有任何平台商标或近似图形，平台来源只用文字标签。

## 文件

- `<前缀>-v20261004.html`：各页线框。只引用 `../tokens/variables.css`、`../tokens/foundations.css` 与本目录的 `wireframe.css`，没有外部资源。
