## 2. 写回内容

- BR-AI-02 ③ 白名单另含：
  - `platform` 的基础设施部分：配置、日志、时钟与调度、数据库连接、Redis、字段加密、鉴权主体、ID 生成、请求校验、熔断限流；**不含任何模块的业务服务**。经数据库连接与 Redis **只读写 Agent 自己的表与键**（表按 04 §3 agent 段；键只许 Agent 自有命名空间），读别模块的数据照旧只走各模块的只读入口。
  - `union` 的类型导入（只 import type）。
- 写的限制由一道新门禁执行（D10-287 ② / D10-288 Q1，归 agent 线）：对 agent 模块做 AST 静态扫描，Kysely 的 insertInto / updateTable / deleteFrom 与原生 SQL 写语句只许出现 Agent 自有表，Redis 键只许 Agent 自有命名空间；主干先确认零违规。门禁合并前，这条限制只靠评审守住；读别模块表的限制目前也只靠评审与只读入口规则。
- 不变：工具集合、只读入口（ledger/read.ts、payout/read.ts）与导出登记、对 growth / commission / settlement 与各模块写服务的禁止。
