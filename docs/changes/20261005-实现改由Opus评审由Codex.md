## 1. 决定内容

1. **主实现**：所有区域一律由 Claude Opus 5.5 子代理写，模型锁定 `claude-opus-5-5`，每个任务在独立 worktree。包括资金、归属、其他交易模块、Agent、H5 与后台、`packages/*`、迁移；三端原生与契约本来就归 Claude，不变。
2. **规则 / 验收测试作者**：Codex，在实现前先写、先红。资金规则测试、归属用例表与回放、AC 映射测试、契约一致性测试、Playwright 冒烟、桥一致性用例、Agent 评测集与注入集（放私有库）都归 Codex。Claude 在内置浏览器里实看仍可做，只作补充证据，不代替 Codex 写的测试。
3. **对抗评审**：所有区域由 Codex 新只读会话评审。RV2（资金、归属、迁移等）保留两家评审：Codex 新只读会话 + Claude 新子代理（与实现子代理不同的新会话），两家都无未关闭的 S0 / S1 才合并。
4. **派工方式**：Opus 实现由编排会话起 Claude 子代理（指定 opus 模型、独立 worktree）；Codex 写测试与评审只经代码仓库 `tools/agent/codex-run.sh`，`impl` 模式用于 Codex 写测试的任务，`review` 模式用于评审。
5. **Opus 5.5 不可用时**：非资金区域按规划/11 §2.5 超限换家处理；资金与归属停，不改由 Codex 实现，除非负责人另行决定。
