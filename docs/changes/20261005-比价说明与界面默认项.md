## 1. 拼多多比价说明可以写平台公开的避免做法

**背景**：功能对照 Q-05 当时按默认 A 写进 BR-PRICE-07 细则「拼多多的比价预判」：不显示假设金额，也不给「收藏后过 N 小时再买」「换个时间再买」这类建议，理由是平台没有公开判定时限。06 记为「待确认」。

**改为**（负责人 2026-10-05 确认）：

1. 比价说明文章（`/v1/config.help_links.price_compare` 打开的那一篇帮助文章，入口见 BR-TEXT-03「比价说明入口」）可以写拼多多官方比价说明里公开的避免做法，共三类：先收藏、过一段时间再从凑狸进入购买；把凑狸生成的下单链接发给家人或好友下单；在凑狸里搜索或粘贴链接后下单。
2. 写法约束（只在 08 BR-TEXT-03「比价说明入口」维护）：转述并注明来源是平台官方说明，不照抄原文；具体等待时长只能写成「平台官方说明建议约 x 小时」这种归属于平台的说法，不写成凑狸的承诺；保留「是否构成比价以平台判定为准」；淘宝没有对应的公开说明，不写淘宝的避免做法。
3. 购买前的比价无返利弹窗（`no_rebate.price_compare.confirm`）增加文字入口「查看说明」，打开同一篇文章；没有配置文章时不显示。新键 `no_rebate.price_compare.help`。弹窗与卡片本身的文案不变，避免做法只写在文章里。

**没有改变的**：

- 不显示「本应返 ¥x」「如果不是比价可返 ¥x」这类假设金额（Q-05 的另一半，负责人没有改，保持）；no_rebate 卡仍不显示任何返利金额（BR-PRICE-21）。
- 拼多多比价预判开关 `rebate.pdd.compare_precheck.enabled` 默认 off、CAP-PDD-04 判为「支持」之前不得打开，不变。开关关闭时购买前不会出现比价弹窗，「查看说明」只在订单侧三处出现（BR-TEXT-03）。
- 文章正文由运营按约束撰写，本次不代拟正文，也不引用平台通知原文。

**受影响的摘要**：01 F-PROD-05 原写「不给等待建议」，改为指向 BR-TEXT-03。

**涉及 BR**：BR-PRICE-07 细则「拼多多的比价预判」（「不展示的内容」一条）、BR-PRICE-08 细则「无返利原因」（展示一条加入口）、BR-TEXT-03「比价说明入口」（文章可写内容与第 ④ 处入口）、BR-TEXT-14 表 C（`no_rebate.price_compare.confirm` 行说明、新增 `.help` 行）、BR-TEXT-12 细则「资金术语键」（新键归普通）。只作引用：BR-TEXT-13（「比价」只在该篇文章放行，不变）、BR-ATTR-10。

## 3. 一并修正的两处规划缺陷

### 3.1 钱包进度行把两件事写成一句

**问题**：08 BR-TEXT-01 钱包汇总口径、BR-FUND-18 的例子和 10 AC-S2-33 都写成「其中已收货 ¥4，预计 11 月结算」。这句读起来像是「已收货的 ¥4 在 11 月结算」，但月份取的是 `next_credit_period`，即各订单预计结算月份里最早的那个（BR-FUND-18），不一定覆盖全部已收货金额。

**改为**：进度行分成两项——「其中已收货 ¥x」与「最早预计 {月份} 结算」，标签用「最早预计」；设计稿已按此改。Agent 收益卡用的是同一个字段，同样写「最早预计」。订单页的单笔「预计 {月份} 结算」不变。

**写到哪里**：08 BR-TEXT-01 细则「钱包汇总口径」及例、BR-TEXT-04「文案」行、BR-FUND-18 例；08 README §1.2「预计 X 月结算」行；10 AC-S2-33；01 §4.2 `Wallet`。字段与取值不变。

### 3.2 「复制口令」与「复制淘口令」

**核对**：未安装淘宝时的按钮（08 BR-TEXT-14 表 C「淘宝未安装」行，原写【复制口令】、提示「口令已复制」）与分享中间页的【复制淘口令】（`share_page.copy_tpwd`，提示「已复制淘口令」）复制的是同一种东西：由我方推广链接生成的淘宝口令（BR-ATTR-27 淘宝行说明、BR-ATTR-10 细则），动作都是写入剪贴板、让人到淘宝里打开。两处只在场景上不同（一个是本人购买的外跳兜底，一个是好友在浏览器里打开分享页），用户看到的对象与动作相同。

**决定**：统一叫「复制淘口令」，复制成功都提示「已复制淘口令」。分享页「包含项」里的「下单口令」（`share.include.tpwd`）是文案里那一行的标签，不是按钮，不改。01 F-SHARE-08 原写【只复制口令】、F-SHARE-10 与 10 AC-S1-138 原写【复制口令】，按 08 `share.copy_tpwd_only`「只复制淘口令」同步为「淘口令」。BR-ATTR-27 里「复制口令」是对动作的描述，不是界面文字，不改。
