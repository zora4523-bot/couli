# 2026-10-31 热销榜与首页信息流在联盟故障时的旧缓存上限

- 决定方式：规划/11 §7.3 第 13 项——原需负责人选择的「待决策」取值由代理用 TypeSafe Jev 判断后回写、事后报告，负责人可随时推翻。
- 起因：w1 B1-28m（#2047）money 评审范围外 S1：08 BR-PRICE-11 只对**搜索与详情**写了「联盟超时或限流时只能返回 age ≤ 300 秒的缓存并标 stale，超过不得返回」；01 F-PROD-13 ⑥ 热销榜「故障读缓存」与 B1-05o 首页信息流复用同一缓存，未写年龄上限，现实现物理保留 24 小时，用户可能看到近一天前的价格。

## 1. 所选做法

联盟超时或限流时，热销榜与首页信息流只返回 **age ≤ `pool.max_age_sec`（默认 7200 秒，后台可调）** 的缓存，标 `stale=true` 并下发 `age_sec`；超过上限：热销榜按该平台暂不可用处理，信息流按 `feed.fallback_pool_id` 走商品池（未配置时为空列表）。用户点打开购买时照常按 BR-PRICE 复核价格，不按缓存价下单。搜索与详情的 300 秒不变。

| 问题 | 概率 |

## 3. 受影响的规划与代码

- 08 BR-PRICE-11 增一句细则（本 PR）。
- 代码仓库：catalog 热销榜读缓存与 B1-05o 信息流读缓存加年龄上限（w1 另开单，不改冻结测试 [AC-B1-28h#22] 的 660 秒用例）。

## 4. 验收与恢复

- 验收：联盟故障注入下，age ≤ 7200 秒的缓存带 stale 返回，超过时热销榜返回暂不可用、信息流走商品池或空列表。
- 恢复：负责人推翻时改 `pool.max_age_sec` 或本条细则取值即可。
