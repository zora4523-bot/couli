# 凑狸品牌色 · 当前采用基线

版本：2026-10-04 / project baseline v0.3.0。在第二版配色基础上按「设计方向第三轮」调整（负责人 2026-10-04 确认，[docs/changes/20261004-设计方向第三轮.md](../../docs/changes/20261004-设计方向第三轮.md) §1）：App 页面底改为 `#F2EEE6`（管理后台仍用 `#F6F3ED`），返利金额与其标签改用橙色系强调，平台来源标签改白底描边，新增图片占位底；其余色值不变。MVP 只做浅色 UI，深色主题留到 P1（规划/03 §10.1）。App 图标的深色外观素材独立于 App 内的主题支持；采用设计基线不代表原生或真机验收完成。

根入口为 [brand.config.json](../../brand.config.json)，所有机器色值唯一维护于 [design-tokens.json](../tokens/design-tokens.json)。下表是使用说明与源数据的可读记录，不作为第二套编辑入口。改色先改 JSON，再维护受影响的说明和对比度，运行 `python3 scripts/sync-brand.py` 生成 CSS / 浏览器配置，并用 `--check` 检查漂移；完整流程见 [品牌接入](../../docs/brand-integration.md)。

方向：**狸橙 + 松叶绿 + 暖米白**。狸橙表达亲近、行动与发现优惠；松叶绿用于可信的完成反馈；米白与深色文字降低商品信息流的视觉噪声。主色集中用于主要行动、选中图形与品牌标记；返利金额与其标签用橙色系强调（第三轮），价格和其他信息不染成橙色，不用红橙渐变、不做整屏大色块。

## 1. 语义配色

| 用途 | 色值 | 令牌路径 | 使用边界 |
| --- | --- | --- | --- |
| 主色 · 狸橙 | `#C44820` | `color.brand.primary` | 主按钮底色、选中图形、Logo；可叠白字 |

| 状态标签 · 预估中 / 待定 | `#655E57` / `#EFEAE2` | `color.status.pending.*` | 「预估中」「等待结算」等状态标签，配钟表图形与状态词；不使用完成对勾；不用于返利金额本身 |
| 成功文字 / 浅底 | `#26735B` / `#EAF4EE` | `color.status.success.*` | 仅已结算 / 已完成，配完成对勾与明确状态词 |

| 错误文字 / 浅底 | `#B42345` / `#FDECF0` | `color.status.error.*` | 莓红配警示图标、原因与可执行的恢复提示，不用于价格 |

## 2. 主按钮与状态

| 状态 | 背景 | 文字 | 交互说明 |
| --- | --- | --- | --- |
| 正常 | `#C44820` | `#FFFFFF` | 每个主要任务区域保持一个清晰主行动 |
| 按下 | `#A83B1F` | `#FFFFFF` | 即时反馈；不通过改变布局尺寸造成跳动 |
| 禁用 | `#E9E2D9` | `#655E57` | 同步禁用语义；必要时给出原因 |
| 键盘聚焦 | 当前状态 + `#26735B` 焦点环 | 当前状态 | 2 单位实线，距控件 2 单位；周围留白保证可见 |

链接与选中项必须同时有下划线、形状、文字或图标等线索。价格（券后价、售价）保持墨棕，使用字号 / 字重表达层级。返利金额与其标签词用返利强调色（白底 / 米白底上 `#A83B1F`，标签底 `#FBEFE8`；24 以上或狸橙实底上可用 `#C44820` 实底配白字），只针对返利金额与标签，不扩大到其他数字（负责人 2026-10-04 确认，docs/changes/20261004-设计方向第三轮.md §1；已结算返利金额是否也用橙色待确认，见 规划/06「设计方向第三轮待确认」）。状态单独承载含义且语义不变：「预估中」「等待结算」使用中性浅底、钟表图形和明确状态词；已结算 / 已完成使用松叶绿浅底、完成对勾和明确状态词。即使去掉颜色，两者也能区分。状态文案与金额口径仍以 BR-TEXT-01、BR-TEXT-04 和 BR-FUND-04 为准，本表不重新定义业务状态。焦点环通过控件外轮廓与状态徽标区分，规则适用于键盘 / 辅助输入，不以常驻描边替代系统原生焦点行为。

## 4. Apple 指南的落实

采用语义颜色、保留足够对比、避免仅靠颜色传达状态，并将品牌色用于聚焦主要行动，依据 [Apple HIG · Color](https://developer.apple.com/design/human-interface-guidelines/color) 与 [Apple HIG · Accessibility](https://developer.apple.com/design/human-interface-guidelines/accessibility)（核对日期：2026-10-01）。

团队采用至少 44 × 44 的逻辑触控命中区，iOS 按 44 × 44 pt，Android / 鸿蒙在本方案采用 48 × 48 dp / vp；这是团队选用的推荐尺寸策略，不是声称 Apple 对所有平台都规定统一的 44 pt 硬性下限。字体使用系统字体并响应系统字号，颜色验收不能代替 Dynamic Type、VoiceOver、焦点顺序与真实设备检查。H5 基础控件提供 `forced-colors` 系统颜色回退；这不等于已经通过 Windows 高对比或 iOS 增强对比验证。实现必须分别检查系统强制配色、增强对比、200% 文字放大、灰度及色觉障碍下的状态辨识，确认字号和布局不会遮挡标签或操作。

机器可读值见 [design-tokens.json](../tokens/design-tokens.json)，H5 变量与用法见 [tokens/README.md](../tokens/README.md)。
