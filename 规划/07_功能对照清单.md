## 1. 结论

| 类别 | 花卷云里的功能 | 新 App 处理 |
| --- | --- | --- |
| 交易与订单核心 | 联盟授权、各平台订单、找回、维权导入与维权渠道、手动同步、处罚订单同步、订单锁定、订单尾号黑名单 | **全部进 MVP**，按新的推广位与归因模型重做 |
| 资金 | 两个钱包、提现设置与审核、余额明细、月结对账、资金记录 | **进 MVP**：用户只有一个余额，流水标明来源（拍板第二批 §8 ADD-06）；复式分录 + 跟随联盟月结批量入账（后台月结账单确认）；自动到账规则组（总开关默认关）与银行卡收款进 MVP；条件模式、灵工、会员月账单 UI 放 P1（D10–D12，拍板第二批 FUND-01～03） |
| 配置与装修 | 首页装修、金刚区、公告、自定义文案、剪贴板、关键词雷达、跳转外部 App、域名管理、弹窗广告 | **大部分进 MVP**（首页 SDUI、配置中心）；个人中心装修、专题页、海报自定义放 P1/P2 |
| 增长与营销 | 拉新、订单红包、0 元购、超级补贴、淘礼金、口令红包、积分商城、营销短信 | MVP 只做**邀请绑定**；淘礼金商品池后续接入、未排期（D7）；拉新奖励、补贴、积分、营销短信 P1；0 元购、订单红包、口令红包 P2 |
| 多级分销与团队 | 代理 / 运营商 / 总代、团队奖、平级奖、全球分红、付费升级、专属邀请等级、超级邀请人、商学院、共享系统 | **不做**（D8：计酬最多直推 + 间推两级，间推开关默认关；其余团队类功能不做） |
| 私域与外部渠道 | 微信矩阵、智能查券、渠道活码、云发单、直播、开放平台 | 服务号查券（D22 已定载体为服务号）与开放平台 P2；云发单、直播**不做** |
| 附加变现 | 移动广告、生活特权卡、特价电影票 | 移动广告 P1；特权卡 P2（仅免费开通，余额不可消费）；电影票不做；信用卡等金融产品推广不做（待负责人确认，§2「14–16 附加变现」，功能对照 G-44） |
| SaaS 自身能力 | 云编译、服务市场、开发者中心 | 不适用（自有 CI 与后台） |
| 合规上不能做 | 审核专用模板 / 审核模式、摇晃广告、夺宝、走路 / 睡觉赚积分、群消息采集 | **不做**；审核模式的技术约束见 §5（2026-10-03 功能对照 G-32） |
