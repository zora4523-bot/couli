## 用途

只用于界面里说明「这是哪个平台的」：

- 商品与订单的平台来源（`PlatformBadge`，规划/03 §10.2）；
- 平台授权（淘宝、拼多多授权页与授权管理页）；
- 支付 / 收款方式（微信支付、支付宝）；
- 分享去向（微信、企业微信等）。

不作品牌宣传。凑狸自己的 Logo、App 图标、启动页和其他品牌素材仍不得包含任何平台商标或近似元素（规划/01 F-PRIV-08，规划/06 Q-F8）。

## 文件名与格式

| 文件名（不含扩展名） | 平台 |
| --- | --- |
| `taobao` | 淘宝 |
| `tmall` | 天猫 |
| `jd` | 京东 |
| `pinduoduo` | 拼多多 |
| `wechat` | 微信 |
| `wechat-pay` | 微信支付 |
| `alipay` | 支付宝 |
| `wecom` | 企业微信 |

- 英文小写加短横线；同一平台有多个版本（如带字 / 不带字、彩色 / 单色）时加后缀，如 `taobao-mark.svg`、`taobao-mono.svg`。
- 格式：优先 SVG；只有 PNG 时边长不小于 512px、透明底。
- 美团等后续平台接入时按同样规则补行。

## 使用要求

- 用官方原图：不改色、不变形、不裁切、不加描边或阴影，保留规范要求的安全距离。
- 标注「仅限签约商户使用」「不得公开分发」一类限制的素材不放进本目录（本仓库公开），改放私有存储，这里只登记文件名与来源。
- 放进来之前先核对上面的来源与规范链接；规范要求与本页冲突时以平台规范为准，并在此更正。
