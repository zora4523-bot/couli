# 变更记录：邀请奖励资格有效期（2026-10-20）

- 状态：已确认（负责人 2026-10-20 在对话中选「设 30 天，看下单时间」）
- 类别：00 §8 第 ② 类（影响用户能否拿到奖励与预算口径，负责人决定）。
- 起因：代码仓库身份线开 B1-35 前提出——资格在绑定时就占用总预算，被邀请人长期不下单时占用永不释放，总预算可能被占满，活动展示随之消失。

## 1. 内容

- 被邀请人取得资格后 30 天内（`growth.invite_reward.eligibility_days`，取得资格时随金额一起锁定）下单的本人自购子订单才可触发；期限内下的单在期限后才月结入账的照发。
- 到期后由每日任务判定：期限内没有自购子订单，或期限内的都已失效 / 基数为 0 → 资格转「已过期」，释放总预算占用；期限内的订单还没有结果的，等有结果再判。
- 「已过期」取代已无路径的「预算用尽」终态（2026-10-19 起总预算在取得资格时占用，不会再出现发放时预算用尽）。
- 活动规则摘要须写明「好友须在绑定后若干天内下单」（天数取配置）。
