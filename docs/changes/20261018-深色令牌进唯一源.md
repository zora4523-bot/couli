## 1. 内容

1. **令牌源结构**（`design/tokens/design-tokens.json`，`couli.tokens.v1` 不变）：每个颜色叶节点在 `value`（浅色）之后加 `dark`（深色），阴影令牌 `shadow.card` / `shadow.floating` 同样加 `dark`（黑色、不透明度 0.30 / 0.45）；尺寸、字号等不随主题变化、没有 `dark`。`metadata.version = 0.4.0`、`date = 2026-10-18`、`theme = "light"`（基准）、新增 `modes = ["light", "dark"]`、`darkThemePhase = "MVP"`（原 `"P1"`）。选这种结构是因为改动最小：现有读 `value` 的消费方不受影响，`sync-brand.py` 只多读一个字段。
2. **深色取值**：38 个既有颜色令牌全部按提案进源；主色、按下态、实底与其上的白字两种主题同值；强调 / 链接 / 返利文字换更亮的橙；页面底、卡片底、分组底、占位底四级暖灰；状态色文字提亮、浅底压暗；App 与后台页面底在深色下同值 `#171513`。
3. **新增令牌 22 个**（T1–T12，浅 / 深都有值；T13 即第 1 项的深色整套）：颜色 6 个——`color.button.inverse.background` / `.text`（卡内白底按钮）、`color.border.active`（输入中描边，深色用主文字色）、`color.overlay.scrim`（遮罩，八位十六进制 `#28251F66` / `#0000008C`）、`color.control.checked`（选中填充）、`color.badge.background`（角标底）；尺寸 16 个——`component.field.min-height` 52、`component.code-cell.height` 56、`component.checkbox.size` 18、`component.checkbox.max-scale` 1.5（新增 `number` 类型）、`component.chip.height` 32、`component.tab-indicator.height` 2、`component.icon.small` / `.inline` / `.medium` 14 / 16 / 20、`component.tag.min-height` 22、`component.platform-badge.min-height` 20、`component.count-badge.size` 18、`component.image.list` 96、`component.grid-cell.min-height` 72、`component.oauth.size` / `.gap` 48 / 32。叶节点 87 → 109。提案里的微信绿、华为红**不进令牌**（平台标识随官方素材走，CLAUDE.md design/ 段）。
4. **对比度复核**（WCAG 2.2：正文 ≥ 4.5、大字 / 控件边界 ≥ 3）：按提案数值逐对重算，全部达标，**没有调整项**；数值表在 `design/colors/colors.md` §3.2。最低的几项：禁用文字 / 禁用底 4.64:1，控件边界 / 卡片底 4.25:1，主色 / 卡片底 3.28:1（只够图形与大字，与浅色同一规则：小字用强调文字令牌）。
5. **生成器**（`scripts/sync-brand.py`）：`variables.css` 输出 `:root` 浅色块（`color-scheme: light`）+ `@media (prefers-color-scheme: dark) { :root:not([data-theme="light"]) }` + `:root[data-theme="dark"]` 两个同值深色块（`color-scheme: dark`，只覆盖带 `dark` 的令牌）；`brand-config.js` 的每个语义角色带 `value` 与 `dark`；颜色接受 `#RRGGBBAA`（CSS 输出 `rgba()`）；新增 `number` 类型；校验：颜色令牌缺 `dark`、非颜色 / 阴影令牌带 `dark`、`metadata.modes` 或根配置 `themes` 不符都报错；`--check` 除字节比对外，另按行核对两个深色块与 JSON 的 `dark` 一致。
6. **根配置**（`brand.config.json`）：新增 `themes`（基准、模式、字段名、CSS 选择器）；语义角色新增 `borderActive`、`overlayScrim`、`controlChecked`、`badgeBackground`、`inverseActionBackground`、`inverseActionText`。
7. **展示页**（`design/brand/`）：`<meta name="color-scheme">` 改 `light dark`；`preview.css` 里承载文字的写死浅底全部改为令牌——交互舞台与图标外观区 `#EAE5DC`、图标底座 `#EEE9E0` → `var(--color-background-muted)`，外观分段底 `#DED9D0` → `var(--color-background-placeholder)`，AI 演示的提问气泡 `#F4DCCE` → `var(--color-brand-subtle)`，演示设置分隔线 → `var(--line)`（深色下这些浅底压亮字只有 1.1–1.9:1；手机边框与商品插画底不承载文字、保留写死）；横版 Logo 在深色下换反白版（`data-brand-asset-dark`，系统主题变化与 `<html data-theme>` 变化都会重新套用）；色值卡显示浅 / 深两个值，点击复制当前主题的值。浅 / 深截图各一套在 couli-runs `design-hifi/tokens-dark-check/`（不入仓库）。
