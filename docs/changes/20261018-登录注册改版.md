## 1. 负责人决定

2026-10-18：报告第 6 节 11 条「全部按推荐」，另定登录页去掉【设置】。逐项如下（取值只在 08）：

1. **本机号码一键登录（iOS / Android）从 P1 提到公开上架前**（M-公开），内测仍只用验证码；**新增供应商阿里云号码认证**（负责人批准）。一键登录为首屏首选、验证码为备用，取号失败或未接入时直接显示手机号验证码页。
2. **鸿蒙：华为账号一键登录作首屏**（Account Kit 官方一键登录组件），时点从 M-公开 提前到**鸿蒙包首次提交华为审核前**；手机号验证码降为「其他手机号登录」。一键登录（运营商与华为）取得的手机号**按手机号登录处理**：号码已有账号就登录那个账号（华为一键登录补记华为身份），没有就新建已绑手机的账号；黑名单、注册风控、协议同意记录同短信登录。
3. **邀请码挪到登录后**：① 登录后的「填写邀请码」页只对本次新建、无上级的账号出现，可跳过、标明选填，老号永不出现；② 已知邀请码（游客点了确认的剪贴板邀请提示条、用户点开并拉起 App 的邀请链接带来的码）随登录请求自动带上，登录页只显示一条可移除的小字；③ 第三方登录新号的绑手机由弹窗改为整页，绑完接「填写邀请码」页，跳过则保留首次购买前提示；④ 先到先得、须已绑手机、补填期限与「有订单不能补填」等取值（BR-INV-03、BR-INV-07）**一条不改**。
4. **验证码页不再二次勾选协议**，同意时间沿用上一步；**输满即自动登录**（位数按 BR-ID-05），去掉【登录】按钮。
5. **「未注册自动注册」并入协议句**，字号、颜色与协议句一致，勾选框保留、默认不勾；一键登录页加运营商或华为认证协议。
6. **勾选框三端统一圆形**，各端用系统画法（iOS SF Symbols，Android 专用矢量图，鸿蒙 ArkUI Checkbox 圆形）。
7. **第三方登录**：同尺寸圆形官方标识按钮，华为在第三方中排第一；Apple 按钮只用纯黑或纯白（Apple HIG）；iOS 可改两颗等宽胶囊（代理定）。
8. **未勾选时的确认框**保留，主按钮按触发的动作命名（获取验证码或登录）、次按钮为不同意（文案键 BR-TEXT-14 表 C `login.agree_confirm.*`）。
9. 验证码页加**求助入口**（`login.code.help_entry`，打开现有帮助文章）；**语音验证码放 P1**。
10. 10a「**上次登录**」标签做；10b「我的」页显示邀请人昵称**不做**（BR-INV-05、BR-INV-18 不变）。
11. **鸿蒙深色模式**：首次提审前用华为预审确认；规划/03 §10.1「系统深色时强制浅色」不变。

另定：**登录页右上角【设置】移除**，游客从「我的 → 设置」进入；登录页保留「登录遇到问题」，协议句里的协议可直接打开。已核对 01「我的」Tab 游客态仍保留【设置】入口（01 §4.1「我的」行、BR-ID-02 细则），未登录到隐私政策的点击路径仍在 4 次以内。

## 4. 受影响的页面与接口

- **页面**：`Login`（三端；一键登录首屏、协议句一段式、确认框按钮、去【设置】与邀请码入口、待绑定码小字、「上次登录」标签、第三方登录行）、验证码页（去勾选框与【登录】按钮、自动提交、「收不到验证码？」）、鸿蒙华为账号一键登录页、运营商一键登录授权页（SDK 提供）、`BindPhone`（第三方新号整页）、`InviteBackfill`（新路由，「我的」补填与登录后一步共用，in_app）、`InviteLink`（只从深链进入的分流入口，不是页面）、H5 邀请落地页（加【在 App 中打开】，05 F1-05）。作废设计稿：`LoginCodeInvite`；`LoginInviteBound` / `LoginInviteFailed` / `LoginBindPhoneGuide` 改为新页面的结果态（设计稿在 couli-runs，由设计线处理）。
- **接口**：新增 `POST /v1/auth/login/one-tap`（provider ∈ {carrier, huawei}，可带 invite_code，形状见 04 §6.1，路径与字段名代理自定、契约线落地）；`POST /v1/auth/login/sms` 不变（仍可带 invite_code）；`POST /v1/me/inviter` 不变（登录后的「填写邀请码」页也用它）；`GET /v1/me` 的 `invite_backfill` 不变。
- **数据**：`users.register_method`、`login_logs.method`、`sessions.login_method` 加 `carrier_one_tap`、`huawei_one_tap`；`user_oauth` 在华为一键登录时按条件补记；`consent_records` 不变（channel 仍 login_page）。
- **隐私政策**（06 Q-F1）：SDK 清单与收集清单加号码认证 SDK、华为一键登录，说明运营商认证服务条款与《华为账号用户认证协议》；新增收集个人信息的 SDK 须升协议版本（BR-ID-12），待法务处理，本次不代写政策正文。
