## 用途

只用于界面里说明「这是哪个平台的」：

- 商品与订单的平台来源（`PlatformBadge`，规划/03 §10.2）；
- 平台授权（淘宝、拼多多授权页与授权管理页）；
- 支付 / 收款方式（微信支付、支付宝）；
- 分享去向（微信、企业微信等）。

不作品牌宣传。凑狸自己的 Logo、App 图标、启动页和其他品牌素材仍不得包含任何平台商标或近似元素（规划/01 F-PRIV-08，规划/06 Q-F8）。

- 放进来之前先核对上面的来源与规范链接；规范要求与本页冲突时以平台规范为准，并在此更正。
