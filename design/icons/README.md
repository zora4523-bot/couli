# 图标

| 子文件夹 | 内容 | 格式 |
| --- | --- | --- |
| `tab/` | 底部 Tab 图标，每个 Tab 一对：常态 `tab-home.svg`、选中 `tab-home-active.svg` | SVG，24×24 画板 |
| `grid/` | 首页金刚区图标（入口宫格），由后台下发，可随时替换 | PNG 120×120 或 SVG |
| `platform/` | 官方平台标识（淘宝、天猫、京东、拼多多、微信、微信支付、支付宝、企业微信），只作平台来源、授权、支付 / 收款方式、分享去向的标识，不作品牌宣传（03 §10.2 PlatformBadge） | 负责人统一准备（2026-10-05），文件名、格式与来源登记见 [platform/README.md](platform/README.md) |

Tab 文案和图标由 `/v1/config` 下发（规划/01 §4），这里放的是包内默认值。
