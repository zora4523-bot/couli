# 2026-11-07 Web 动效令牌与动效规范（H5 与管理后台）

- 类别：实现方案与令牌补充（00 §8 第 ① 类），只加键、不改已有令牌值；依据 00 D37（三端原生组件优先）与编排裁定 D10-837 ①。
- 起因：前端线的手感方案（D10-834 ③）查明 H5 除骨架外全部硬切、全库没有动效令牌，管理后台有 30 处主动关掉组件动画；设计标准整改计划的 DSX-03（令牌升版二）、DSX-12（交互规范）、DSX-13（动效规范）都缺 Web 的数。D37 之后原生三端用各自平台默认动效（`design/ui-rules/ios.md`、`android.md`、`harmony.md`），只有 Web 需要自己定数。

## 1. 新增令牌（`design/tokens/design-tokens.json`，v0.5.1 → v0.5.2）

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `motion.duration.instant` | 0ms | 立即生效；减弱动态下无法改为淡入的动画 |
| `motion.duration.fast` | 150ms | 微交互：按压态、颜色 / 透明度、开关与勾选、选中态 |
| `motion.duration.normal` | 250ms | 常规状态切换与小元素进出：展开收起、内容替换、轻提示进出 |
| `motion.duration.emphasized` | 350ms | 较大面积进出：底部弹层、对话框、整块内容切换 |
| `motion.duration.slow` | 500ms | 少用的整屏强调过渡；装饰动效上限 |
| `motion.easing.standard` | cubic-bezier(0.2, 0, 0, 1) | 屏内移动与状态变化 |
| `motion.easing.enter` | cubic-bezier(0, 0, 0, 1) | 进入（减速停下） |
| `motion.easing.exit` | cubic-bezier(0.3, 0, 1, 1) | 退出（加速离开） |
| `motion.easing.emphasized-enter` | cubic-bezier(0.05, 0.7, 0.1, 1) | 大面积进入 |
| `motion.easing.emphasized-exit` | cubic-bezier(0.3, 0, 0.8, 0.15) | 大面积退出 |
| `motion.toast.display` | 2000ms | 轻提示停留（不含进出过渡），与现有 H5 一致 |
| `motion.skeleton.shimmer` | 1500ms | 骨架微光扫过一次的周期 |
| `motion.skeleton.show-delay` | 300ms | 加载超过本值仍未返回才显示骨架 |
| `motion.skeleton.min-visible` | 300ms | 骨架显示后至少保留本值 |
| `motion.reduced.fade` | 150ms | 减弱动态时位移 / 缩放改为只淡入淡出所用时长 |

取值依据：时长档与缓动取 Material 3 公开的 easing and duration 令牌（short3 150、medium1 250、medium3 350、long2 500；standard、standard-decelerate / accelerate、emphasized-decelerate / accelerate 的贝塞尔值），250ms 与常见系统默认动画时长一致；减弱动态按 WCAG 2.2 SC 2.3.3。每个令牌的 description 注明「仅 Web，原生不读」。

## 2. 生成器与文档

- `scripts/sync-brand.py` 新增 `duration`（`unit: "ms"`，输出 `150ms`）与 `cubicBezier`（四个数，x1、x2 限 0–1，输出 `cubic-bezier(…)`）两种类型；`variables.css` 多 15 个 `--motion-*` 变量，`brand-config.js` 随 metadata 更新。两份生成物由脚本生成，未手改。
- `design/tokens/README.md` 转换表加 `duration`、`cubicBezier` 两行，令牌计数 116 → 131。
- `规划/03_前端架构.md` 新增 §10.6「动效（Web）」：令牌对照、用法、减弱动态、原生不读；`design/ui-rules/README.md` §3.3 加指针。

## 3. 与 DSX 整改计划的关系

- 本次兑现 DSX-03 ①（motion 令牌与两种新类型）、DSX-13 中 Web 部分（动效规范节）、DSX-12 ⑦ 加载防闪的数值。命名照 DSX-03 ① 原拟的 `instant / fast / normal / slow` 与 `standard / enter / exit`，另加 `emphasized` 时长与两条强调曲线；DSX-03 ① 原拟的 `motion.skeleton.pulse` 改为 `motion.skeleton.shimmer`（D10-837 定骨架用微光）。
- DSX-03 ⑥ 原写「本单只加键、不改 metadata.version，由 DSX-02 统一升 v0.6.0」：本次按编排裁定 D10-837 单独升 **v0.5.2**，便于前端线（DSX-48 起）锁定消费；DSX-03 其余部分（layout、叠放层级、反色标题栏、阴影换算）与 DSX-02 的 v0.6.0 照原计划。
- 原生三端：DSX-13 ②「转场目录」里原生部分按 D37 改为各平台系统默认转场，不读 motion 数。三端锁令牌版本照常随各自 TOKENS 单升，不为本组单独升；三端生成器升锁到 v0.5.2 时需认得或跳过 `duration`、`cubicBezier` 两种类型。

## 4. 验收与恢复

- 验收：`python3 scripts/sync-brand.py --check` 通过；生成的 CSS 带 15 个 `--motion-*` 变量；`jq '.tokens.motion' design/tokens/design-tokens.json` 取得到；`python3 scripts/kanban.py --check --local` 无新增 WARN。
- 恢复：只加键，回退即删除 `tokens.motion`、生成器两种类型并重新生成；不影响任何已有令牌值。
