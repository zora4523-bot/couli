### 0.2 验证状态

| 状态 | 含义 | 谁能改成这个状态 |
| --- | --- | --- |
| 未开始 | 没有执行任何实验 | — |
| 进行中 | 已开始实验或已提交权限申请 | 执行人 |
| 支持 | 通过标准全部满足，证据齐全 | 调度人（你）确认后 |
| 部分支持 | 可用但有已证实的限制；降级方案已实现并验收 | 调度人确认后 |
| 不支持 | 实验证明不可用，或平台书面答复不予开通 | 调度人确认后 |
| 被阻塞 | 权限未批、真机或测试账号未到位；须写明阻塞项与预计解除日期 | 执行人 |

**硬规则**：

1. 状态不是"支持"的能力，**不得写进对外承诺、验收用例的必过项或营销文案**。"部分支持"只能按已证实的范围表述，并带上降级文案。
2. 代理不得把状态改成"支持 / 部分支持 / 不支持"，只能提交证据并把状态改成"进行中"；改判由调度人签字（日期 + 姓名写进 `result.md`）。
3. 联盟接口未获批前，代理只能用录制回放（`config/union-endpoints.yaml` 标 `mode=replay`）开发，**禁止臆造响应**。
4. 需要 appKey / secret 的探测脚本不在代理会话里运行：一次性脚本由人在本机运行；长时脚本由人部署到探测运行环境（§0.3.1）自动执行。代理只写脚本、读输出与录制，不持有密钥（02 §6.2）。负责人列写"代理写脚本 / 人部署与批准 / 探测环境执行"的即指这种分工；写"代理"的只限不需要密钥的工作（写脚本、整理录制、写报告）。压测类实验（TB-12、JD-12、PDD-12、PDD-13 批量上限）运行前须人批准，并受第 5 条约束。
5. **测试单与压测（新 App 与优券汇共用联盟账号）**：真实测试单与压测都记在共用账号上，出问题两个 App 同时受影响（淘宝推广者违规可被关闭 API 权限、2 个月内不得再申请〔ALIMAMA-1578·中〕；京东 validCode 41 / 42 违规，见 JD-12）。
   - 真实测试单（V-14、V-15、V-22、V-25、V-39 及各平台 05 / 07 / 08 / 11 的下单步骤）开始前，须拿到该联盟对测试单报备的书面答复（淘宝 V-01 / 06 Q-G5，京东 V-02，拼多多 V-05，美团 V-38）。拿不到答复时按默认限额执行：每个买家账号每天 ≤3 单、单笔实付 ≤30 元、每个平台每天 ≤10 单（默认值，待调度人确认），每单登记在 `evidence/capabilities/<CAP-ID>/test-orders.csv`（日期、买家账号代号、订单号后 6 位、目的），并把登记表邮件报备联盟对接人。
   - 压测：先书面或凭控制台截图确认配额按 appkey 还是按联盟账号计算。按账号计算时**不做压测**，只记录控制台配额与文档值；按 appkey 计算时只在 10-14 前（10-15 双11 预售开始）、02:00–06:00 低峰、只压非订单接口，出现首个限流错误立即停止，并提前 1 个工作日通知优券汇运营。订单接口一律不压测、不主动触发限流（淘宝订单限流按账号计：约 200 次/秒，其中 API 约 40 次/秒〔TOP-43328·中（抓取摘要）〕），限流错误码以文档为准，正常同步中出现时录制。

### 0.5 可信度与来源写法

- 事实后的 `〔来源·可信度〕`：高 = 官方文档原文（本地 `evidence/sources/` 存有原文截图、HTML 或 JSON，可复核）或本次实测；中 = SDK 注释转述官方、二手资料、搜索摘要，以及经网页抓取工具转写 / 摘要读到的官方页（写作"中（抓取摘要）"）；低 = 单一二手来源或推断。来源短名见附录 B。
- **`evidence/sources/` 尚未建立**（2026-09-30 核对：项目目录下无 `evidence/`；原始资料仍在会话临时目录，见附录 A-22）。建立并移入原文之前，标"高"的官方文档类条目一律暂按"中"理解；本次实测类"高"须有 `evidence/capabilities/<CAP-ID>/` 证据才成立。
- 接口名只出现在二手资料里的，标"候选，以官方文档为准"。
- 官方文档（developer.alibaba.com、jaq-doc.alibaba.com）经网页抓取工具读取，工具做过转写或摘要；拼多多开放平台文档须登录，本轮字段全部来自 SDK 注释转述。**W0 由人登录各平台逐一核对字段名与限额**（V-06）。
- **淘宝 / 百川条目降级**（2026-09-30）：抽查 TOP-65409、TOP-64763 发现三处转写与原文不一致却标了"高"（万能转链邀约制的适用范围、biz_scene_id=3 的含义、material_type 枚举名），本地也没有存官方原文。因此所有 `TOP-xxxxx`、`TOP-OAUTH`、`BC-*` 来源的事实一律为"中（抓取摘要）"；第 6 节"目前已知"列里引用这些来源写的"（高）"同样按"中（抓取摘要）"理解。V-06 由人登录 TOP 逐条核对 TB 各条的字段、枚举、限额，把原文截图或 HTML 存 `evidence/sources/taobao/`，核对一致的条目改回"高"并在来源后注明核对日期。京东 `JD-API(...)` 为官方 JSON 原文，保持"高"；`JD-DIR` 目录留存不完整，按"中（目录未完整留存）"（见 §3.1）。
