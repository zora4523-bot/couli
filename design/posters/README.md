# 海报

- `share/`：商品分享海报模板风格（规划/01 F-SHARE-01）；
- `invite/`：邀请好友海报背景图（BR-INV-18，后台可配置背景图，需人工审核）。

规则（设计时要留出位置）：
- 商品海报必须有：主图、券后价、券额、取价日期与口径说明、二维码；**不得显示返利金额**（BR-PRICE-06、BR-PRICE-17）；
- AI 生成的文案或图片要带隐式标识（BR-ID-15）；
- 是否标「推广」由法务定（06 Q-F7），版面上预留角标位置；
- 不得出现「原价」「到手价」等禁用词（BR-PRICE-04、05、18）。

尺寸：竖版 750×1334 起（可按 1080×1920 出图）。
