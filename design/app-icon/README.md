# App 图标

只需要你提供下面三个文件，三端全部尺寸由 Claude 生成：

| 文件 | 规格 | 用途 |
| --- | --- | --- |
| `icon-1024.png` | 1024×1024，PNG，**不透明、不带圆角**（系统自动裁圆角） | iOS、商店 |
| `icon-foreground.png` | 1024×1024，PNG，**透明底**，只放图形，主体保持在中间约 66% 的圆形安全区内 | Android 自适应图标、鸿蒙分层图标的前景层 |
| `icon-background.png` | 1024×1024，PNG，纯色或简单图案，不透明 | 前景层的背景 |

可选：`icon-monochrome.png`（1024×1024 透明底单色剪影），用于 Android 13 起的主题图标。

生成结果放在 `ios/`、`android/`、`harmony/` 子文件夹，不用手动放。各商店提交前以其最新规格为准。
