# 变更记录：告警与风控事件名点号化（2026-10-18）

- 状态：已写回（编排会话裁定 D10-48，负责人可随时推翻）
- 来源：代码仓库订单线 B1-08i 入队告警事件时被 `platform/events` 的 EVENT_NAMES 冻结测试拒绝：测试要求事件名形如 `a.b`，而 02 §11 末尾登记的四个告警与风控事件是下划线名。
- 类别：命名同步缺陷（00 §8 第 ① 类），只改事件名字符串，不改任何 BR 的取值、状态迁移、告警级别或编号，不新增 BR。
- 受影响接口：无（领域事件是进程内任务名，不对外）。
- 受影响任务：B1-08i（订单线，以 test-change 跟进）；contracts / `platform/events` 的 EVENT_NAMES 冻结清单。

## 问题

02 §11 的 19 个正式事件都是 `a.b` 点号形式，同段末尾另列的 `order_attr_param_changed`、`order_illegal_transition`、`attr_binding_conflict`、`blacklist_hit_after_credit` 用下划线名，且不在正式清单内。代码仓库事件总线只接受 `a.b` 形式的事件名，订单同步 worker 无法把这四个事件与业务写入同一事务入队（BR-ATTR-01 ⑦ 要求同事务）。

## 改法

| 旧名 | 新名 | 说明 |
| --- | --- | --- |
| `order_attr_param_changed` | `order.attr_param_changed` | 告警，BR-ATTR-01（已归属订单归因参数变化，P2 告警） |
| `order_illegal_transition` | `order.illegal_transition` | 告警，BR-ATTR-01、BR-FUND-01 P10（表外事件与倒退，与待处理表记录同事务） |
| `attr_binding_conflict` | `order.attr_binding_conflict` | 告警，BR-ATTR-07（多条绑定命中且用户不同，P1 告警） |
| `blacklist_hit_after_credit` | `order.blacklist_hit_after_credit` | 进人工复核，BR-ATTR-26（已 CREDITED 命中黑名单） |

四个事件并入 02 §11 正式事件清单（19 → 23 个），仍在业务事务内入队；「BR-TEXT-09 等处的消费者清单以本节事件名为准」不变。

## 涉及 BR
